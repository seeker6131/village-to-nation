# บ้านเรา ประเทศเรา (Village to Nation) — v0.7 Character Creator

ต้นแบบเกมแนวนอน HTML5/Canvas แบบไฟล์เดียว พร้อมห้องแต่งตัว **ครั้งแรกที่เข้าเกม** และเมนูแต่งตัวอีกครั้งภายหลัง ใช้ชุดตัวละครที่ผู้ใช้แนบมา 4 ภาพ ไม่ได้เจนรูปใหม่

## เล่นอย่างไร

- เปิด `play_standalone.html` (ไฟล์เดียว มีรูปบรรจุอยู่แล้ว) หรือเปิด `index.html` ในโฟลเดอร์นี้ผ่านเว็บเซิร์ฟเวอร์
- เข้าเกมครั้งแรก: ตั้งชื่อตัวละครภาษาไทยหรืออังกฤษ 2–20 graphemes, เลือกทรงผม 3 แบบ, เลือกสีชุด 4 แบบ, ดู 4 ทิศทางด้วยลูกศร, กดเริ่มใช้ชีวิต
- เปิดครั้งต่อไป (หากเบราว์เซอร์ให้สิทธิ์ localStorage) จะข้ามห้องแต่งตัวไปเลย และตัวละครยังคงเดิม
- ภายในเกม: เมนู `👕 แต่งตัว` เปิดห้องใหม่เพื่อแก้ชื่อ ทรงผม และสีชุดได้
- ส่วนอื่น ๆ ของเกม v0.6 ยังคงอยู่: เดิน/ซูม/เต็มจอ, NPC, เวลา, งาน, ซื้อขาย, ก่อสร้าง, ผัก, สอบและผู้นำจำลอง

> บางเบราว์เซอร์บนมือถือจำกัด localStorage เมื่อเปิดไฟล์ HTML ผ่าน `file://`. หากต้องการบันทึกข้อมูลที่เชื่อถือได้ ให้วางไฟล์บน HTTPS หรือ PWA (ระบบบัญชีออนไลน์ยังไม่พัฒนา)

## โครงสร้างไฟล์

- `index.html` — โครงการ HTML ใช้ Sprite atlas จาก `assets/atlases/`
- `play_standalone.html` — HTML ไฟล์เดียว ฝังภาพ atlas ทั้ง 12 ชุด (ไม่ต้องใช้เน็ต)
- `assets/original/` — PNG ต้นฉบับจากผู้ใช้ 4 ภาพ
- `assets/layers/` — `base_4x4.png` และ hair-only 4×4 แยก 3 ทรง (ทุกไฟล์ RGBA 256×256)
- `assets/atlases/` — สไปรต์ฐาน+ผม+สีเสื้อ รวม 12 ชุด (256×256)
- `build_assets.py` — แยก 16 เฟรมด้วย connected-component และจัดตำแหน่งให้ตรงกันใหม่
- `source/v2n_inline_v06.html` — ต้นแบบระบบเกมก่อนเพิ่มห้องแต่งตัว
- `integrate.py` — เพิ่มระบบแต่งตัวเข้า HTML เดิมและสร้าง HTML แบบไฟล์เดียว
- `tests/browser_test.py` — บราวเซอร์เทสต์ด้วย Playwright (Chrome/Chromium) โดยใช้ localStorage mock เพราะสภาพแวดล้อมทดสอบจำกัดการเปิด URL
- `preview/` — ภาพหน้าจอที่ทดสอบจริง
- `CLAUDE.md` — เอกสารส่งต่องาน

## บันทึกตัวละคร

อยู่ใน `localStorage['v2n-inline-06']` เดิม ใน property `character`:

```json
{
  "name": "ต้นกล้า",
  "hair": "bob",
  "outfit": "green",
  "lang": "th"
}
```

การแต่งตัวไม่เปลี่ยนเงิน/XP/ตำแหน่งเดิม ชื่อจะถูกใช้เฉพาะแสดงบน HUD และเก็บในเซฟ ปัจจุบันยังไม่มีระบบตรวจชื่อซ้ำบนเซิร์ฟเวอร์

## ข้อจำกัดจริง

- รูป AI ต้นฉบับมีเฟรมเดินผิดเพี้ยนบางเฟรม ขณะนี้ปรับตำแหน่งด้วยโปรแกรมแล้ว แต่ยังต้องให้ pixel artist ทำความสะอาดเพื่อใช้ในผลิตภัณฑ์จริง
- ทรงผม 3 ตัวเลือกจากไฟล์ที่แนบมามีความคล้ายกันเมื่อมองด้านหน้า; เมนูช่วยดูด้านหลังซึ่งแยกกันได้ชัดขึ้น
- ชุดปัจจุบันเป็นเสื้อชั่วคราวที่สร้างด้วยโค้ด ยังไม่ใช่ชุดอาชีพ
- ยังไม่ใช่ระบบ character creator หลายเพศ/สีตา/สีผิวทั้งหมด
- ทดสอบเฉพาะ Chrome/Chromium แบบจำลองหน้าจอ ไม่ได้ยืนยันกับ iOS Safari/Windows native จริง
- ยังไม่มีเซิร์ฟเวอร์ ออนไลน์ ซื้อสินค้าเงินจริง หรือเลือกตั้งออนไลน์
