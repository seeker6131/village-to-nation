# บ้านเรา ประเทศเรา — Village to Nation · v0.9 (Wild Forest Start)

เกม 2D Top-Down Pixel Art 16-bit แนวใช้ชีวิต + สร้างหมู่บ้าน → ชุมชน → เมือง → ประเทศ
**สถานะ: ต้นแบบออฟไลน์เล่นคนเดียว (single-player prototype) — ยังไม่ใช่ OBT ออนไลน์ ไม่มีระบบรับเงินจริง**

**v0.9:** เริ่มเกมกลางป่าทึบที่สร้างจาก seed (แต่ละเกมไม่ซ้ำ) มีบ้านผู้นำหลังเดียว ขวาน 1 เล่ม และ NPC ผู้ช่วย 4 คน — ถางป่า ขุดตอ แล้วสร้างหมู่บ้านขึ้นมาเอง ผู้เล่นเป็น "ผู้ก่อตั้ง" ที่เป็นผู้นำรักษาการ แต่ต้องรักษาความนิยมและชนะเลือกตั้งทุกวาระ (ไม่ Pay-to-Win)

v0.8 รวมโค้ดแยกโมดูลของ v0.5 เข้ากับห้องแต่งตัว/ซูม/เต็มจอ/จอแนวนอนของ v0.7 แล้วสร้างระบบตัวละครใหม่จากภาพต้นฉบับ · ดูทั้งหมดใน `CHANGELOG.md`

## ระบบที่ใช้งานได้จริง (ตรวจด้วย automated tests)

- **ตัวละครแบบ Modular**: sprite 4×4 = 16 เฟรม ขนาด 64×64 · เดิน หน้า/ซ้าย/ขวา/หลัง · alpha โปร่งใสจริง · ผม 3 ทรง ซ้อนตรงหัวทุกเฟรม · เปลี่ยนสีผม สีผิว 5 ระดับ สีตา 5 สี ชุด 12 แบบ (ฟรี 4 / ชุดอาชีพ 5 / ชุดร้าน 3)
- **ห้องแต่งตัว**: ครั้งแรกก่อนเข้าเกม · ตั้งชื่อไทย/อังกฤษ (2–16 ตัวอักษร) · TH/EN · หมุนดู 4 ทิศ + ดูท่าเดิน · แก้ภายหลังได้ (ยกเลิก = ไม่บันทึก)
- **NPC ใช้ระบบตัวละครเดียวกับผู้เล่น** (สเกลเท่ากัน เดิน 4 ทิศ) มีอาชีพ ตารางชีวิต ไปทำงาน กินข้าวที่ตลาด ประชุมที่ศาลา นอนตอนกลางคืน และ**เปลี่ยนพฤติกรรมตามสิ่งที่หมู่บ้านสร้าง**
- **ก่อสร้าง**: เลือกจากเมนู → กรอบตัวอย่างเขียว/แดง → ตรวจเขต สิ่งกีดขวาง คน เงิน วัตถุดิบ → ยืนยัน/ยกเลิก (ไม่หักของจนกว่ายืนยัน) → สร้างตามเวลาในเกม (ช่าง NPC มาช่วย ผู้เล่นช่วยด้วยพลังงาน) → อัปเกรดระดับ 2–3
- **เศรษฐกิจ**: ตลาดมีสต็อกจริง ราคาขึ้นลงตามสต็อก · สวนชุมชนผลิตอาหาร · โรงงานผลิตแผ่นไม้ (จ่ายค่าเช่าให้ผู้เล่น) · NPC ซื้ออาหารกลางวัน (ภาษีเข้าคลังเมือง) · ผู้อยู่ใหม่ย้ายเข้าเมื่อมีบ้าน · เงิน/ของ**ติดลบไม่ได้**
- **งานและอาชีพ**: รับงาน → มีลูกศรนำทาง → เดินไปทำที่สถานที่จริง · อาชีพให้ค่าแรง +20% และปลดล็อกชุดอาชีพ
- **ภารกิจ**: บทนำครูอุ่น 8 ขั้น · งานประจำวัน · คำขอจาก NPC 8 เรื่อง (รับ/ส่งโดยคุยกับ NPC)
- **ราชการ ≠ การเมือง**: สอบราชการ → เข้าเวร → เลื่อนขั้นตามวันทำงาน · สายผู้นำ: สอบผู้นำ + ผลงาน + โครงการครบ + เลือกตั้ง (จำลอง NPC) → บริหารคลังเมือง · นายกฯ ต้องใช้คุณสมบัติ+ผลงาน+เลือกตั้งในอนาคต ไม่มีทางจ่ายเงินปลดล็อก
- **ระดับพื้นที่**: ค่ายบุกเบิก → หมู่บ้าน → ชุมชน → เมือง (ประเทศ = ล็อก รอระบบออนไลน์)
- **ร้าน OBT (โครงสร้าง Mock)**: แฟชั่น/เฟอร์นิเจอร์/Supporter Pack/ความสะดวก · ปุ่มซื้อปฏิเสธเสมอ (ไม่มีการตัดเงิน) · ลองสวมได้ · กฎห้าม Pay-to-Win ตรวจด้วย test
- **ตั้งค่า**: FPS 30/60/120 (จำกัดการวาดจริง) · Low/Medium/High (เปลี่ยนความละเอียดเรนเดอร์ เงา แสงไฟกลางคืน น้ำระยิบ หิ่งห้อย อัตราแอนิเมชัน NPC) · ตัววัด FPS · เสียงเอฟเฟกต์/บรรยากาศ/ปิดเสียง
- **กล้อง**: ซูม 2 นิ้ว/ล้อเมาส์/ปุ่ม แบบพิกเซลคมทุกระดับ · ลากเลื่อน · โหมดดูทั้งเมือง · เต็มจอ (ล็อกแนวนอนเมื่อแพลตฟอร์มอนุญาต)
- **แผนที่**: tilemap หลายชั้นจาก seed + ภูมิประเทศ 4 แบบ (`?seed=123&biome=coast` ใช้ดูตัวอย่างตอนทดสอบ) ต้นไม้/หินเป็นวัตถุที่ตัด/ขุดได้จริง และบันทึกในเซฟ
- **เซฟ**: key เดิม `v2n-prototype-v1` · อัปเกรดเซฟ v0.5 อัตโนมัติ (สำรองไฟล์เดิม) · นำตัวละครจาก v0.7 มาใช้ต่อ · เซฟเสียไม่ทำให้เกมพัง

รายละเอียดว่าอะไรจริง อะไร mock อะไรยังไม่มี: **`docs/STATUS_V08_TH.md`**

## นักพัฒนา

```bash
npm test                 # 60 unit tests (กฎเกม เซฟ sprite กล้อง ร้านค้า)
npm run build            # สร้าง play.html จาก src/
npm run test:e2e         # 14 browser tests (Playwright + Chromium) + ภาพหน้าจอ qa/screens/
npm run build:characters # สร้าง sprite atlas ใหม่จาก source_art/characters (ต้องมี Python + Pillow + numpy + opencv)
```
