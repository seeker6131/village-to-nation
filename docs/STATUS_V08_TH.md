### บั๊กที่พบใน v0.7 (แก้แล้วใน v0.8)
1. **ผมด้านข้างหันผิดทาง**: ไฟล์ร่างกายเรียงแถว ลง/ขวา/ซ้าย/ขึ้น แต่ไฟล์ผมเรียง ลง/ซ้าย/ขวา/ขึ้น → v0.7 ซ้อนผมหันตรงข้ามกับหน้า ปิดตา
2. **ขยายภาพทีละเฟรม** (LANCZOS สูงคงที่ 52px / ผมกว้างคงที่) → เฟรมที่ยกขาถูกบีบ สัดส่วนเพี้ยน
3. **ขอบแดง/โปร่งแสงครึ่งๆ** จากการลบพื้นหลังยังติดอยู่
4. ผมด้านหลังวางต่ำ ทับตัว · หัวโดนตัดขอบบนเฟรม
5. ชุดเป็นรูปหลายเหลี่ยมวาดทับ ไม่ตามท่าเดิน
6. ตั้งค่า Low/Medium/High แทบไม่เปลี่ยนการเรนเดอร์

- ก่อสร้างเสร็จทันที ไม่มีเวลา · อาคารตกแต่งไม่มีผลกับ NPC · NPC เดินตามเวลาแต่ไม่มีผลเศรษฐกิจ

## งานถัดไปที่แนะนำ (เรียงตามความสำคัญ)
1. **ทดสอบบนมือถือจริง** Android + iPhone แนวนอน (ทดสอบแล้วเฉพาะ Chromium จำลองจอ)
2. **ให้นักวาด pixel art** ทำ layer เสื้อผ้าจริง (top/bottom/shoes แยกไฟล์ 4×4 ใช้ anchors.json เดียวกัน) + ทำความสะอาดเฟรมเดินด้านข้าง (ต้นฉบับ AI ทุกเฟรมเป็นท่าก้าว ไม่มีท่ายืน)
3. แปลงฉากเป็น tilemap แยกชั้น (พื้น/วัตถุ/การชน/หลังคาบัง) — ตอนนี้การชนกำหนดมือใน `world.js`
4. มินิเกมงานสั้น ๆ (ตกปลา ส่งของ ก่อสร้าง) ให้ทำงานสนุกกว่ากดปุ่ม
5. Balance เศรษฐกิจด้วยการเล่นจริง 1–2 ชั่วโมง (ราคา ค่าแรง เวลาก่อสร้าง)
6. แปลเมนูทั้งหมดเป็น EN
7. ออกแบบ API เซิร์ฟเวอร์: บัญชี, เศรษฐกิจ authoritative, ที่ดิน, เลือกตั้ง, entitlement ร้านค้า + webhook ชำระเงิน
