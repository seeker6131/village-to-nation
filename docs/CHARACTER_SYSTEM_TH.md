## รูปแบบ atlas
- 256×256 px = 4 คอลัมน์ × 4 แถว เฟรมละ **64×64**
- แถว: 0 = หน้า (down) · 1 = ซ้าย · 2 = ขวา · 3 = หลัง (up)
- คอลัมน์: 0–3 วงจรเดิน (ยืน/ก้าว/ยืน/ก้าว สำหรับหน้า-หลัง) · `idleCol` ใน anchors บอกเฟรมยืน
- **เท้าแตะ y = 61** ทุกแถว (เฟรมที่ยกขา ห่างไม่เกิน 2px) · หัวแต่ละแถวอยู่ตำแหน่งเดียวกันทุกเฟรม (ไม่สั่น)
- alpha เป็น 0 หรือ 255 เท่านั้น
- ในเกมวาดที่สเกล 0.72 พิกเซลโลก (`CHAR_SCALE`) — ตัวสูงประมาณ 37px ใกล้เคียงอาคาร v0.5

## สิ่งที่สคริปต์ทำ
1. ลบขอบแดง/ครึ่งโปร่งแสงจากการลบพื้นหลัง (สีแดงที่อยู่ในตัว เช่นยางรัดผม คงไว้)
2. หา 16 ตัวในภาพที่ความละเอียดเต็ม แล้วย่อ **ด้วยอัตราเดียวทั้งไฟล์** (ร่างกาย 1/5.5, ผม 1/7.5) — ไม่ยืด/บีบรายเฟรม
3. เรียงแถวใหม่ให้เป็น หน้า/ซ้าย/ขวา/หลัง (ภาพร่างกายต้นฉบับแถว 1 = ขวา แต่ภาพผมแถว 1 = ซ้าย)
4. จัดร่างกาย: หัวแต่ละแถวตรงกันทุกเฟรม เท้าแตะ baseline
5. Fit ผม: หาตำแหน่งที่คลุมกะโหลกมากที่สุดแต่ไม่บังตา แล้วใช้จุดยึดเดียวกันทุกเฟรมในทิศนั้น
6. ผมที่ต่ำกว่าคอในมุมหน้า → ย้ายไปชั้นหลัง (วาดหลังตัว)
7. แยก material ต่อพิกเซล: skin / eye / brow / hair / underwear / outline / tie / fixed และ body part: head / torso / arm / leg / foot (+สัดส่วนความยาวแขนขา 0–7) → ใช้ระบายเสื้อแขนสั้น/ยาว กางเกงขาสั้น/ยาว รองเท้า

## เพิ่มของใหม่ภายหลัง
- **ทรงผมใหม่**: วางภาพ 4×4 แบบเดียวกันใน `source_art/characters/` เพิ่มใน `HAIR` ของ build script + `HAIR_STYLES` ใน model.js แล้วรัน `npm run build:characters` ตรวจ `contact_sheet.png` และ `npm test`
- **เสื้อผ้าจริงจากนักวาด**: วาดบน body_base_4x4.png (กริดเดียวกัน) แยก top/bottom/shoes เป็นไฟล์โปร่งใส → เพิ่มชนิด layer ใน composer (วาดหลัง body ก่อน hair_front) แทนการระบายสี
- **ชุดอาชีพ/ร้านค้า**: เพิ่มใน `OUTFITS` (`source: 'free'|'job'|'shop'`) ชุดร้านต้องมี sku ใน `src/shop.js` และไม่มีผลต่อค่าพลังใด ๆ
- **สีใหม่**: เพิ่มใน `SKIN_TONES` / `HAIR_COLORS` / `EYE_COLORS` (rgb = สีหลัก ระบบคงแสงเงาเดิมให้)

## ข้อจำกัดที่ยังมี (ห้ามอ้างว่าสมบูรณ์)
- ต้นฉบับ AI ด้านข้างทุกเฟรมเป็นท่าก้าว ไม่มีท่ายืนนิ่ง → ยืนด้านข้างใช้เฟรมก้าวแคบที่สุด
- รายละเอียดผมบางเฟรมต่างกันเล็กน้อย (ต้นฉบับเป็นแบบนั้น) — ควรให้นักวาด clean up ก่อน OBT
- มุมหน้า ผมทรงปัดข้างมีช่องหน้าผากกว้างตามต้นฉบับ (skull cover 0.76)
- เสื้อผ้าตอนนี้คือการเปลี่ยนสีบริเวณร่างกาย ยังไม่ใช่ภาพเสื้อผ้าจริง
