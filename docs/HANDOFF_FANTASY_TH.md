## ทิศทางใหม่ที่เจ้าของเกมสั่ง (ยังไม่ได้เริ่ม)
- เลิกธีมไทย → อาณาจักรแฟนตาซี มีพระราชาปกครอง · เริ่มจากเด็กหนุ่มชาวบ้าน → ผู้ปกครองที่เป็นรองพระราชา
- คอนเซ็ปเดิม: บริหารบ้านเมือง + ไต่เต้าสู่ตำแหน่ง · ไม่มี pay-to-win
- บ้านแค่ 3 ระดับ: จน (กระท่อม) / มีกิน (บ้านไม้) / เศรษฐี (คฤหาสน์)
- อาชีพ: ตัดไม้ หาปลา ช่างตีอาวุธ ก่อสร้าง ทหาร ล่าสัตว์ ชาวนา พ่อค้า ขุดแร่ ฯลฯ
- เงิน: เงิน (silver) เป็นเงินหลัก, ทองมีค่าสูง · ธนาคาร (ชื่อแฟนตาซี เสนอ "หอเงินตรา"/"กิลด์พ่อค้า")
- เริ่มเกมมีแค่ปราสาทพระราชา · เมืองเล็ก → อาณาจักรใหญ่ · ค้าข้ามเมือง · ฤดูกาล · ศัตรูบุก (สัตว์ประหลาด ทหารต่างแดน)
- ทำแมพใหม่ 5 แบบ ไม่ซ้ำ ปราสาทอยู่กลางแมพ มีเนิน/หน้าผาสวยๆ · โละภาพและระบบไทยเก่า

## ข้อเสนอที่รอเจ้าของเกมตอบ
1. ตำแหน่งสูงสุด = "อัครมหาเสนาบดี" (มือขวาพระราชา)?
2. เริ่มเป็นทาส แล้วไถ่ตัว? (นอนเรือนทาส → เช่าเตียงโรงเตี๊ยม → บ้านตัวเอง)
3. ขึ้นตำแหน่งด้วยพระราชาแต่งตั้ง (ชื่อเสียง + ความนิยมชาวบ้าน + ความโปรดปรานของพระราชา) แทนเลือกตั้ง?
- บันไดที่เสนอ: ทาส → ชาวบ้านอิสระ → หัวหน้าหมู่บ้าน → อัศวิน/ขุนนางชั้นผู้น้อย → เจ้าเมือง (บารอน) → เจ้าแคว้น (ดยุก) → อัครมหาเสนาบดี
- สายทหารแยก: ทหาร → นายกอง → อัศวิน → แม่ทัพ (แทนสายข้าราชการเดิม)
- ระบบโกงกินคงไว้ (โดนจับ = พระราชาปลด ริบทรัพย์)

## กฎของเจ้าของเกม (ห้ามละเมิด)
- คุยภาษาไทยแบบเป็นกันเอง กู/มึง
- ห้ามขายคะแนน/ตำแหน่ง/ความได้เปรียบ · ห้ามต่อเงินจริงก่อนมีเซิร์ฟเวอร์ตรวจสอบ
- ห้ามบอกว่าเสร็จเพราะหน้าเกมเปิดได้ — ต้องรันเทสและเปิดดูในเกมจริงทุกยุคก่อนส่ง
- prompt รูปให้ GPT: 1 รูปต่อ 1 บล็อก ครบในตัว · 16-bit pixel art · พื้นหลัง magenta #FF00FF (ยกเว้นแผ่นพื้น)
