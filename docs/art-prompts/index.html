ชุดคำสั่งเจนภาพทั้งเกมที่สเกล สไตล์ และเลย์เอาต์ตรงกันทุกรูป ก๊อปทีละการ์ด วางใน GPT ได้ 1 รูปต่อ 1 การ์ด แล้วส่ง PNG กลับมาตามชื่อไฟล์ที่ระบุ

กติกาก่อนเจน

  1. บรรทัด แนบ = รูปที่ต้องแนบไปกับ prompt (ไม่มีบรรทัดนี้ = ไม่ต้องแนบ)
  2. ได้รูปแล้วตั้งชื่อตาม ชื่อไฟล์ ในการ์ด แล้วส่ง PNG มาตามที่ได้ ไม่ต้องตัดเอง
  3. ถ้า GPT ใส่พื้นหลังมา ให้สั่งซ้ำ: "make the background flat magenta #FF00FF" กูลบออกเอง
  4. รูปไหนสัดส่วนเพี้ยน หรือมีตัวหนังสือติดมา สั่งเจนใหม่ทั้งรูป อย่าแก้บางส่วน
  5. สีผม สีผิว สีตา และสีเสื้อผ้า ไม่ต้องเจนแยก เกมเปลี่ยนสีให้เอง ให้เจนแค่ทรงหรือแบบ
  6. กด "เจนแล้ว" เพื่อจำว่าทำรูปไหนไปแล้ว (จำแค่ในเครื่องนี้)
