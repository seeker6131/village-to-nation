# สเปกงานภาพ (Art Pipeline) — v0.9

คลัง prompt ทั้งหมด: `docs/art-prompts/index.html` (173 การ์ด มีปุ่มก๊อป) — ทุก prompt ฝังสเปกด้านล่างไว้แล้ว

## มาตรฐานร่วม
- 16-bit pixel art มุมบน 3/4 แสงจากซ้ายบน เส้นขอบน้ำตาลเข้ม 1 px ไม่มี anti-aliasing ไม่มีตัวหนังสือ
- สเกล: ผู้ใหญ่สูง 52 px (ในเกมวาดที่ 0.72 = ~37 px) · ช่องพื้น 16×16 px
- พื้นใส PNG หรือพื้นชมพูล้วน #FF00FF (สคริปต์ลบให้) · ของแต่ละชิ้นห่างกัน ≥ 32 px
- ชื่อไฟล์ตามการ์ด → วางใน `source_art/incoming/` แล้วรันสคริปต์แยกชิ้น

## ยุค (ระดับพื้นที่ = เลเวลภาพอาคาร)
| Lv | ยุค | วัสดุ |
|---|---|---|
| 1 | บุกเบิก | ไม้ซุง ไม้ไผ่ หญ้าคา |
| 2 | หมู่บ้าน | เรือนไทยใต้ถุนสูง กระเบื้องดินเผา |
| 3 | ชุมชน | อิฐฉาบ + ไม้ 2 ชั้น |
| 4 | เมือง | ตึกแถวคอนกรีต |
| 5 | มหานคร | กระจก เหล็ก หลังคาสวน |

อาคาร 1 ชนิด × 1 ยุค = 1 รูป มี 4 ขั้น: เริ่มสร้าง → โครง → ใกล้เสร็จ → เสร็จ (ใช้กับแถบความคืบหน้าก่อสร้างในเกม)
บ้าน NPC ใช้ภาพยุคเดียวกับระดับพื้นที่ จึงพัฒนาตามหมู่บ้านอัตโนมัติ

## ตัวละคร
- **ผู้เล่น = ซ้อนชั้น**: body → ผม (24 ทรง) → หนวด/เครา (6) → เสื้อ (12) → กางเกง/กระโปรง (8) → รองเท้า (4) → หมวก/แว่น (10) ทุกชั้นเป็น 4×4 เฟรม กริดเดียวกับ base body
- สีผม/ผิว/ตา/ผ้า เปลี่ยนในเกม (เจนแค่สีกลางๆ มีแสงเงา)
- **NPC = ภาพสำเร็จ** แต่ละคนมี 5 ยุค หน้า/ผม/อาชีพคงเดิม (ต้องแนบรูป Lv1 ตอนเจนยุคอื่น)

## สถานะการต่อเข้าเกม
- ✅ ระบบซ้อนชั้น body + ผม + เปลี่ยนสี (ใช้แล้ว) · โครงสร้าง material/part map รองรับเสื้อผ้าแบบเปลี่ยนสี
- ⏳ ชั้นเสื้อผ้า/หนวด/หมวกจากภาพจริง, NPC ภาพสำเร็จ, อาคารตามยุค 4 ขั้น, สัตว์, tileset — โค้ดรอภาพ (สคริปต์ fit แบบเดียวกับผม)
