# Village to Nation: Fantasy Kingdom — เกมออกแบบ v0.30 (Draft for Owner Review)

> **สถานะ**: เอกสารออกแบบฉบับเสนอ ไม่ใช่การยืนยันว่าระบบทุกอย่างใช้งานแล้ว
>
> ค่าตั้งต้นตามคำสั่งเจ้าของเกม: เริ่มเป็นทาส, ตำแหน่งสูงสุดอัครมหาเสนาบดี, พระราชาแต่งตั้ง; แก้ได้ก่อนรื้อระบบก้าวหน้าภายหลัง

## แก่นเกม
- เกม 2D 16-bit top-down 3/4 โลกแฟนตาซี โทนเย็นนุ่มป่าเขียวอมฟ้า เมืองเติบโตจากปราสาทพระราชาแห่งเดียว
- ผู้เล่นเริ่มเป็นไพร่/ทาสรับใช้ที่ไร้ทรัพย์ ฝึกอาชีพ ปลดพันธะ ไต่เต้าผ่านชื่อเสียง ความไว้วางใจประชาชน ผลงานและพระราชาทรงโปรดปราน
- เป้าหมายสูงสุดในเวอร์ชันแรก: **อัครมหาเสนาบดี** เป็นผู้มีสิทธิ์ออกคำสั่งอัปเกรดอาคารสาธารณะ แต่ไม่มีสิทธิ์แทนพระราชา/ข้ามกลไกตรวจสอบ
- 20 นาทีจริงเท่ากับหนึ่งวันในเกม (คงระบบเดิม) เวลาจำลองอิง delta-time ไม่ใช่ FPS

## วงจรการเล่น
1. ตื่นที่โรงนอน / บ้าน → ตรวจสุขภาพ พลังงาน ข่าวประกาศ ราคาอาหาร และภารกิจ
2. เลือกงาน: ตัดไม้ ชาวนา ประมง ตีเหล็ก ขุดแร่ สร้างบ้าน พ่อค้า ทหาร ล่าสัตว์
3. ทำมินิเกม/เก็บวัตถุดิบ รับเงิน, เพิ่มความชำนาญอาชีพ, ทำงานที่ยกระดับความเป็นอยู่คนเมือง
4. อุปโภคบริโภค/สะสมเงิน ซื้อที่/อุปกรณ์/อาหาร/เช่าที่พัก/อัปเกรดที่อยู่อาศัย
5. รับงานหลวงและภารกิจชาวบ้านเพื่อเพิ่มชื่อเสียง ความนิยม และความโปรดปรานของพระราชา
6. สั่งงานเมืองเมื่อมีตำแหน่ง, รับมือศัตรูบุก, พัฒนาเส้นทางค้าข้ามเมือง, วางแผนเตรียมฤดูกาลหน้า

## โครงสร้างสังคมและแต่งตั้ง
| ลำดับ | ยศ | บทบาท | เงื่อนไขหลัก |
|---|---|---|---|
| 0 | ทาสรับใช้ | งานหลวงเบื้องต้น | เริ่มเกม บริโภค/ที่พักขั้นต่ำ ไม่ถูกผูกกับการเติมเงินจริง |
| 1 | ราษฎรอิสระ | เป็นเจ้าของบ้าน/ค้าขาย | ไถ่ตัวด้วยเกมเพลย์ที่มีทางเลือกหลายทาง ไม่ต้องใช้เงินจริง |
| 2 | ผู้ใหญ่บ้าน | พิจารณางานหมู่บ้าน | ชื่อเสียง ผลงานดูแลคนในพื้นที่ และความเห็นชอบของราษฎร |
| 3 | อัศวิน/ขุนนางผู้น้อย | รับราชการส่วนพระองค์ | ได้รับพระราชาแต่งตั้งหลังทำภารกิจพิสูจน์ความสามารถ |
| 4 | เจ้าเมือง (บารอน) | งานบริหารเมืองและบัญชีเมือง | ชื่อเสียง + ความนิยม + ความโปรดปราน + ไม่มีคดีทุจริต |
| 5 | เจ้าแคว้น (ดยุก) | คุมขุนนาง แคว้นและถนนการค้า | เศรษฐกิจ สวัสดิการ และการป้องกันเมืองอยู่เกณฑ์ |
| 6 | อัครมหาเสนาบดี | รองพระราชา | ผลงานข้ามแคว้น ความโปรดปราน และประชาชนยอมรับ |

คะแนนสามแกน 0–100: `reputation`, `popularity`, `royalFavor` แยกกัน; พระราชาแต่งตั้งเมื่อครบทุกเกณฑ์ **เท่านั้น**. ขุนนางที่ทุจริตถูกสอบสวน ยึดทรัพย์/ริบยศได้ตามกฎในเกมและมีช่องทางอุทธรณ์ ไม่ขายทางลัด.

## เศรษฐกิจและที่อยู่อาศัย
- `silver` เงินทั่วไป; `gold` เงินมูลค่าสูง, อัตราแลกเปลี่ยนกำหนดโดยระบบเศรษฐกิจ (เริ่มที่ 100 silver = 1 gold เพื่อบาลานซ์; ปรับภายหลัง)
- รักษา `player.coins` เป็น silver ภายในเพื่อให้อ่านเซฟ v2n-prototype-v1 ได้โดยไม่ต้องล้างความคืบหน้า; UI เปลี่ยนเป็นชื่อ **เหรียญเงิน**.
- อาคารธนาคารใช้ชื่อ **หอเงินตรา**, แยก **กิลด์พ่อค้า** สำหรับการแลกสินค้า
- บ้าน 3 ระดับ: **จน** กระท่อม → **มีกิน** บ้านไม้ → **ร่ำรวย** คฤหาสน์; งานอัปเกรดใช้เงินและทรัพยากรที่หาได้ในเกม
- อาคารสาธารณะ 3 ระดับ ตามเศรษฐกิจและคำสั่งเจ้าเมือง; NPC อัปเองเมื่อเงื่อนไขครบ โดยสุ่ม/ตัดสินใจแบบ deterministic ไม่ให้ผู้เล่นต้องจ่ายเงินจริง

## NPC, เครื่องแต่งกาย, การเซฟ
- ทุก NPC มีข้อมูล `look` เฉพาะตัวที่สร้างครั้งเดียว (ID + seed) และบันทึกไว้ใน `s.town.fantasyLooks`; อาชีพกำหนดชุดที่เหมาะสม ไม่สุ่มซ้ำทุกเฟรม
- Character paperdoll ใช้ PNG sheet ผู้เล่นย้อมผม/เคราได้; ชุด/หมวกไร้สถานะเพิ่มพลัง; canvas nearest-neighbour เลเยอร์ทุกเฟรมลง atlas 4 ทิศ × 9
- เซฟ `v2n-prototype-v1`; ข้อมูลใหม่เพิ่มแบบ additive พร้อม migration แบบ deterministic ทุกเวอร์ชัน

## ฤดูกาล
ฤดูใบไม้ผลิ → ร้อน → ใบไม้ร่วง → หนาว (ทุก 7 วันเกม = 1 ฤดูสำหรับต้นแบบ); พืชผล ผลผลิตปลา อัตราค่าครองชีพและพฤติกรรม NPC ต่างกัน แต่ผู้เล่นยังหารายได้ทุกฤดูได้

## อันตราย/การป้องกันเมือง
- สัตว์ประหลาดจากป่า/ถ้ำ และทหารต่างแคว้นบุกเป็นเหตุการณ์ประกาศล่วงหน้า ทหาร NPC ป้องกันเองได้
- ความเสียหายเกิดกับกำแพง คลังและอาคารเมือง ไม่ทำให้เซฟ/ทรัพย์สินผู้เล่นหายแบบกะทันหันโดยไม่มีทางแก้
- ฟื้นเมืองด้วยเศรษฐกิจจริง: ค่าก่อสร้าง ค่าจ้างทหาร ค่าซ่อม ไม่สร้างทรัพยากรติดลบ

## ภูมิประเทศและ 5 แผนที่
1. หุบเขามงกุฎ — ลำธารเหนือ-ใต้ ปราสาทกลางที่ราบ มีสันเขาตะวันตก
2. ทะเลสาบจันทร์หมอก — บ่อน้ำและป่าไม้เบียดเนินหน้าผาตะวันออก
3. แคว้นสนคราม — ป่าสนด้านเหนือ ผาหินเป็นชั้น หมู่บ้านย่อยชิดฐานเขา
4. ทุ่งกวางทอง — ทุ่งลมเย็น แปลงนา รอบปราสาท เนินเตี้ยสองด้าน
5. ช่องเขาอัศวิน — ผาคู่ขนาบช่องเขา สะพานการค้าเชื่อมต่างเมือง

แผนที่ทุกแบบสร้างจาก seed คงที่ พร้อมทางผ่านหน้าผาเฉพาะ `cliff_stairs`, ปราสาทอยู่กลางพื้นที่และไม่ทับจุดเกิดตัวละคร.

## ภายในอาคาร / การพัก
- เดินถึงประตูแล้วกดเข้าหรือ auto-cross threshold → เปลี่ยนฉาก ภายในเป็นห้องแยกพื้นบ้าน/ร้าน/กิลด์; NPC เจ้าของร้านอยู่หลังเคาน์เตอร์
- ประตูทางออกชัดเจนและคืนตำแหน่งภายนอก; มีฟังก์ชันนอนที่บ้าน/โรงเตี๊ยมพร้อมกฎตรวจค่าเช่า → ข้ามเวลาถึงเช้าและเติมพลังงาน
- ป้องกันการข้ามวันซ้ำไร้เหตุ; เก็บเวลาและสถานะภายในไว้ในเซฟ

## UI, ประสิทธิภาพ, กราฟิก
- Landscape บนมือถือ; 30/60/120 FPS, Low/Medium/High มีผลจริงและ persist
- แสงคืนจากจุดไฟ/เทียน/หน้าต่างเป็น glow gradient นุ่ม มี flicker ตาม seed ทำแบบ pre-render cache หรือ light pass ให้ Low ปิดได้
- Sprite atlas 80x80px ต่อเฟรม (80×9 x 80×4); วาดตัวละคร 0.5 world px/texture px ให้พิกเซลไม่แตก

## กฎธุรกิจ / OBT
- **ห้าม Pay-to-Win** ไม่มีขายเงินในเกมที่ซื้อความได้เปรียบ ตำแหน่ง ความโปรดปราน คะแนนสอบ อาวุธแรง หรือเร่งการเลื่อนขั้นด้วยเงินจริง
- Mock shop อนุญาตเฉพาะชุด เครื่องตกแต่งบ้าน skin / เฟรม / สี / ของประดับ และการจัดการ UI ที่ไม่เพิ่มอำนาจ
- ก่อนรับเงินจริงต้องมี server-authoritative receipt verification, entitlement API, abuse prevention, refund / chargeback handling และ privacy design; ไม่ต่อ payment ในต้นแบบ
