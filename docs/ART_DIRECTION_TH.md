# Village to Nation — คู่มือสไตล์ภาพ v1 (30 ต.ค. 2026)

ตัดสินใจโดย Toey: ทั้งเกมใช้สไตล์เดียว (ไม่แบ่งยุคภาพ) — เมืองฝรั่งน่าอยู่ แนว Stardew Valley, โทนอบอุ่น สบายตา
ระดับพื้นที่ (หมู่บ้าน → อำเภอ → จังหวัด → ประเทศ) ยังอยู่ แต่สิ่งที่โตคือ "มีอะไรในเมือง" ไม่ใช่สไตล์ภาพ

## กติกาภาพ (ใส่ในทุกพรอมต์)
- 16-bit pixel art, มุมก้ม 3/4 (top-down 3/4), แสงจากซ้ายบน, เงา 2-3 โทน, พิกเซลคม ไม่มี anti-alias
- เส้นขอบสีน้ำตาลเข้ม 1 พิกเซล เฉพาะวัตถุ (อาคาร ต้นไม้ ของ คน) — ช่องพื้นไม่มีเส้นขอบ
- พาเลต: หญ้าเขียวอ่อนอบอุ่น, ดินน้ำตาลอ่อน, หลังคาสีอิฐ/น้ำเงินหม่น/เขียวหม่น, ผนังครีม ขาวนวล ไม้, น้ำฟ้าเทอร์ควอยซ์
- อาคาร/ของ: พื้นหลังม่วงแดง #FF00FF, ไม่วาดพื้น สนาม ลานจอด รั้ว หรือต้นไม้ติดมา
- ภาพที่เจนออกมาสวยสุดของรอบแรก ใช้แนบเป็นภาพอ้างอิงสไตล์ทุกครั้ง

## ตารางขนาด (1 ช่อง = 16 px ในเกม = ความกว้างตัวละคร)
- คน 1×2 ช่อง, ประตู กว้าง 1 ช่อง สูง 1.5 ช่อง
- ต้นไม้ใหญ่ 3×4, ต้นเล็ก 2×3, พุ่มไม้ 1×1
- กระท่อม 3×3, บ้านเล็ก 4×3, บ้านกลาง 5×4, บ้านสองชั้น 5×5, บ้านหรู 7×5
- แผงร้าน 2×2, ร้านชำ 4×3, มินิมาร์ท 5×3, ซูเปอร์มาร์เก็ต 8×4
- ป้อมตำรวจ 2×2, โรงพัก 6×4, สถานีตำรวจใหญ่ 8×5
- ที่ว่าการอำเภอ 8×5, ศาลากลาง 10×6, ทำเนียบ 14×8
- อนามัย 5×3, รพ.อำเภอ 8×5, รพ.จังหวัด 12×7
- สำนักงานเช่า 4×3, ตึก 3 ชั้น 5×5, อาคารสำนักงาน 6×8, ตึกสูง ฐาน 6 สูง 16
(ตัวเลข = กว้าง × สูงในภาพ รวมหลังคา)

## ขั้นงาน
A คู่มือนี้ · B พื้น ต้นไม้ ถนน ผังเมือง · C บ้านต่อชิ้นส่วน (ไม่ซ้ำกัน) + ร้าน/ราชการอัปเกรดหน้าตาเปลี่ยน · D ในบ้าน (นอน ครัว พัก ตู้เสื้อผ้า) · E ตัวละคร (ผม หนวด เครา เสื้อผ้าแยกชิ้น)

## พื้นตามชีวิตจริง
- ถนนหลัก: ลาดยาง + ทางเท้า · ซอยบ้าน: ถนนเล็ก · หน้าบ้าน: สนามหญ้า + ทางเดินหินถึงประตู + ที่จอดรถ
- ลานเมือง: อิฐ/หินปู · ดิน: เฉพาะทางในป่าและไร่นา · พุ่มไม้วางเป็นจุด ไม่กระจาย
