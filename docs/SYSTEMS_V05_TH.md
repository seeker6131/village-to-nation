# ระบบที่พัฒนาแล้วจริง — Village to Nation v0.5

วันที่เอกสาร 28 ตุลาคม 2026 · **ระบบมาก่อนภาพ** · เกมต้นแบบออฟไลน์

## เป้าหมาย

2D top-down, 16-bit-style life sim, ผู้เล่นเริ่มจากคนธรรมดาในหมู่บ้านที่มี NPC ผู้ดูแลชั่วคราว ครูอุ่นสอนหาเงิน เก็บทรัพยากร ก่อสร้าง สอบราชการ และแข่งขันเป็นผู้นำชุมชน ภายหลังจึงพัฒนาไปสู่เมือง ประเทศ และออนไลน์ที่มีพลเมืองคนจริง

## ระบบ UI ที่ใช้ได้จริง

| UI | ข้อมูล/ปุ่ม | โค้ด |
|---|---|---|
| HUD บน | วัน/เวลา เหรียญ ไม้ หิน | `src/main.js` `hud()` |
| บาร์ตัวละคร | พลังงาน/100, XP/XP ที่ต้องใช้, เลเวล, ตำแหน่งงาน | `hud()` / `requiredXp()` |
| ปักหมุดภารกิจ | ภารกิจครูอุ่นปัจจุบัน; แตะไปคู่มือ | `mentorObjective()` |
| เมนูล่าง | ภารกิจ กระเป๋า งาน ก่อสร้าง ผลิต ตลาด อาชีพ ผู้นำ OBT | `index.html` และ `openPanel()` |
| กระเป๋า | จำนวนวัตถุดิบ เมล็ดอาหาร ผลผลิต อุปกรณ์; กินอาหาร, อัปสกิล | `inventoryContent()` |
| โหมดก่อสร้าง | เลือกอาคาร → แตะพิกัด → preview เขียว/แดง → ยืนยัน/ยกเลิก | `enterBuild()`, `canPlace()`, `placeBuilding()` |
| ตลาด NPC | ซื้อเมล็ด/อาหาร/ไม้/หิน ขายผลผลิตและของที่ผลิต | `marketContent()`, `buyMarket()`, `sellMarket()` |
| ผลิต | แปรรูปไม้ → แผ่นไม้; แผ่นไม้+หิน → ชุดเครื่องมือ (ต้องมี workshop) | `craft()` |
| ภารกิจรายวันในเกม | เก็บไม้ 3, หิน 2, ส่งพัสดุ 1; รับรางวัลได้ครั้งเดียวต่อวันในเกม | `refreshDaily()`, `claimQuest()` |
| ราชการ | ข้อสอบ + ทำงานรายวัน + เลื่อนตำแหน่ง | `takeCivilExam()`, `civilShift()` |
| เลือกตั้ง | คุณสมบัติ + สมัคร + นับคะแนน **จำลอง NPC เท่านั้น** | `runDemoElection()` |
| สำนักงานผู้ใหญ่บ้าน | ผู้นำที่ได้รับเลือกใช้ **งบ NPC** อนุมัติโครงการพัฒนาสาธารณะ | `adoptCivicAction()` |
| ตั้งค่า | 30/60/120 FPS, Low/Medium/High, แสดง FPS จริง | `src/performance.js` |

## เศรษฐกิจทดลอง

- เริ่มเหรียญ 35, เมล็ด 2, อาหาร 2, พลังงาน 100
- ซื้อ: เมล็ด 5, อาหาร 10, ไม้ 7, หิน 8 เหรียญ (ส่วนลดสกิลค้าขาย)
- ขาย: เมล็ด 1, อาหาร 4, ไม้ 3, หิน 4, ผัก 8, แผ่นไม้ 6, ชุดเครื่องมือ 18 เหรียญ
- เก็บไม้/หินใช้พลังงาน 5 ลดได้จากสกิลเก็บของ สูงสุดใช้เพียง 2
- ผลผลิตแปลงผัก: ใช้เมล็ด 1 → ผ่านเวลา 1 วันในเกม → ได้ผัก 3 และ XP 12
- การขายในตลาดสมมติ NPC เพิ่มคลังเมือง +1 ต่อหนึ่งรายการ (เงินนี้ไม่หักรายได้ผู้เล่น)
- สกิลเป็นผลจาก XP ที่เล่นได้เท่านั้น ไม่ขายด้วยเงินจริง

## สิ่งปลูกสร้างส่วนตัว

| อาคาร | footprint (tile) | ไม้ | หิน | เหรียญ | ผลต่อระบบ |
|---|---|---:|---:|---:|---|
| แปลงผัก | 3×3 | 2 | 1 | 6 | ปลูก/เก็บผัก |
| ม้านั่ง | 2×1 | 2 | 0 | 4 | ตกแต่ง |
| โคมไฟ | 1×1 | 1 | 1 | 8 | ตกแต่งยามค่ำ |
| โรงงานงานฝีมือ | 4×3 | 5 | 4 | 25 | ปลดล็อกสูตรชุดเครื่องมือ |

- ตรวจสิ่งกีดขวางของแผนที่ทุก tile ใน footprint, อาคารเดิม, ขอบโลก และโซนก่อสร้างด้านขวา
- วางอาคารแล้วหักทรัพยากรทันที; มีรูปแทนที่วาดด้วย Canvas ไม่พึ่งรูปจริง
- อาคารตกแต่งบางอย่างยังไม่มีผลต่อ NPC หรือเศรษฐกิจ นี่คือ TODO โดยตั้งใจ
- โครงการสาธารณะ 4 แห่งยังอยู่ในจุดที่กำหนดเดิม; ไม่ให้ผู้เล่นลากย้าย เพราะมีผลต่อเนื้อเรื่อง/การเลือกตั้ง

## รัฐบาลจำลอง

- ครูอุ่น NPC ดูแลชุมชนก่อนการเลือกตั้ง
- เปิดเลือกตั้งหลังสร้างโครงการสาธารณะครบ 4 และสอบ/ผลงานผ่านตามเกณฑ์
- คะแนนเลือกตั้งเป็นสูตรออฟไลน์ที่ตั้งใจให้ทดลองการไต่ระดับ ไม่ใช่ระบบเลือกตั้งออนไลน์
- หากผู้เล่นได้รับเลือกจะมีหน้าบริหารคลังเมือง จำลองการอนุมัติไฟถนน สวนหย่อม และมุมอ่านหนังสือ
- ไม่มีการยึดบ้าน การเก็บเงินแบบ P2W การซื้อเสียง การรับสมัครนายกประเทศ หรือผู้เล่นจริงในรุ่นนี้

## เรื่องเซฟและความปลอดภัย

- ใช้ `localStorage` ชื่อ `v2n-prototype-v1` แบบเดิม โดย `ensureSystems()` เติมโครงสร้าง state ที่รุ่นก่อนยังไม่มี
- เก็บการตั้งค่า FPS/กราฟิกแยกจากเซฟเกม
- ตั้งใจหยุดเวลาตอนเปิดหน้าต่างเมนู เพื่อไม่ทำให้พลาดเหตุการณ์ขณะอ่าน
- โค้ดนี้เป็น client authoritative **สำหรับออฟไลน์เท่านั้น**; หากจะทำออนไลน์ห้ามให้เบราว์เซอร์เป็นผู้ตัดสินเงิน ทรัพยากร ตำแหน่ง และคะแนนเลือกตั้ง

## เงินสนับสนุน OBT

- มีตัวอย่าง UX ร้าน OBT **ยังไม่มีการเติมเงินจริง**
- ขายชุดแฟชั่น กรอบโปรไฟล์ ตกแต่งบ้าน/พื้นที่ส่วนตัว หรือเครื่องมือจัดชุด/บันทึกแบบแปลนได้ แต่ไม่เพิ่มความเร็วการสร้าง รายได้ เหรียญ คะแนนสอบ หรือคะแนนเลือกตั้ง
- ให้ทุกคนผ่านการสอบและเป็นผู้นำได้โดยไม่ต้องจ่ายเงิน
- แผนรับชำระต้องมีระบบเซิร์ฟเวอร์ยืนยันใบเสร็จ การมอบของแบบไม่ซ้ำ ประวัติซื้อ การคืนเงินและการป้องกันธุรกรรมปลอม ก่อนเปิด OBT

## จุดที่ยังไม่สมบูรณ์

- เศรษฐกิจ NPC ยังเป็น mock ทั่วไป ไม่ใช่ตลาดที่มี supply/demand ตามจริง
- ก่อสร้างทันที ยังไม่มีระยะเวลาสร้าง/คนงานและหนังสือกรรมสิทธิ์ที่ดิน
- ยังไม่ทำ tilemap แยกชั้น; ฉากเดิมใช้ภาพ background เต็มผืน
- NPC เดินตามเวลา แต่การตัดสินใจเชิงเศรษฐกิจยังไม่มี
- ไม่ได้ทำระบบ auth, backend, real time multiplayer, บัตรประชาชนในเกม, ภาษีจริง, การเลือกตั้งออนไลน์, AI API, ชำระเงิน
- ไม่รับประกัน 120 FPS จริงบนจอที่ไม่รองรับ
